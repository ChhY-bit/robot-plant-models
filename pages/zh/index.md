## 为机器人建模提供清晰基础。 {#a-clear-foundation-for-robot-modeling}

Robot Plant Models 关注平面移动机器人的运动和执行器动态。当前实现基于 MATLAB；原生 Python 和 C/C++ 库属于未来规划，目前尚未提供。

安装说明、快速开始和详细模型推导仍在完善中。您可以先查阅已有的机器人 API 参考，并从[版本发布页面](https://github.com/ChhY-bit/robot-plant-models/releases)获取发布包。
